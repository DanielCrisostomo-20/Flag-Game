#  Flag Game

## Sobre o projeto

O Flag Game é um aplicativo desenvolvido em Flutter e Dart para testar os conhecimentos dos jogadores sobre as bandeiras dos países.

O jogador deve observar uma bandeira e escolher a alternativa que corresponde ao país correto antes que o tempo termine.

## Funcionalidades

-  Jogo por continente: África, América, Ásia, Europa e Oceania.
-  Jogo aleatório com países de diferentes continentes.
-  Configuração do tempo: 30 segundos, 60 segundos, 3 minutos e 5 minutos.
-  Perguntas com bandeiras e alternativas de países.
-  Sistema de pontuação.
-  Tela de resultados com acertos e percentual de aproveitamento.
-  Salvamento do recorde no dispositivo.
-  Menu principal com logo personalizada.

## Tecnologias utilizadas

- Flutter
- Dart
- Android Studio
- Shared Preferences para salvar o recorde.

## Organização dos arquivos

- `lib/main.dart`: código principal e telas do aplicativo.
- `lib/paises.dart`: dados dos países, bandeiras e continentes.
- `assets/`: imagens utilizadas no aplicativo.
- `pubspec.yaml`: configuração do projeto e suas dependências.

## Como executar o projeto

1. Instale o Flutter e o Android Studio.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no Android Studio.
4. Abra o terminal na pasta principal e execute:

```bash
flutter pub get
flutter run
```

É necessário ter um emulador Android iniciado ou um celular conectado e configurado para executar o aplicativo.
